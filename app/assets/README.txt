Assets para build EAS

Os seguintes arquivos PNG devem estar nesta pasta para que a build compile sem avisos:

- icon.png: Ícone do app (mínimo 192x192px, recomendado 1024x1024px)
- splash.png: Splash screen (recomendado 1080x2340px para vertical)
- adaptive-icon.png: Ícone adaptativo Android (192x192px)
- favicon.png: Favicon para web (recomendado 192x192px)

Até que esses arquivos sejam criados, a build do Expo usará imagens default e exibirá avisos.
